##  How to Run the Project from Scratch

To run this project locally, follow these steps:

### 1. Clone the Repository

```bash
git clone https://github.com/JovaniAntonio/portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Open in Browser

Simply open `index.html` with your preferred web browser:

- Right-click `index.html` and choose "Open With" → your browser  
**or**
- Use VS Code Live Server extension to serve it locally
